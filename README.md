# Notion Greeting Widget  

## Overview  
A custom embeddable widget for Notion dashboards, designed to display a personalized greeting.  

## Features  
- Embed via iframe for seamless integration.  
- Lightweight and responsive.  
- Simple customization for user preferences.  

## Tools & Technologies  
- HTML5, CSS3  
- Notion widget embedding
